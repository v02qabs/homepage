ご提示いただいたHTMLデータを元に、以下の処理を自動で行うPythonスクリプトを作成しました。

### このスクリプトが自動で行うこと
1. **`index.html` の作成**: 提示されたHTMLコードで `index.html` を作成します。
2. **ファイルのコピー**: `index.html` を `python3.html` にコピーします。
3. **リンク（アクティブ表示）の自動更新**: 
   フォルダ内にあるすべての `.html` ファイル（`index.html`, `python3.html` など）をスキャンし、**それぞれのファイル名に合ったメニュー項目のリンクに `class="active"` を自動付与**（他からは削除）します。
   * `index.html` では「トップページ」がアクティブ（緑色）になります。
   * `python3.html` では「python」がアクティブ（緑色）になります。

---

### Pythonスクリプト (`setup_html.py`)

以下のコードを `setup_html.py` という名前で保存して実行してください。

```python
import os
import re
import glob
import shutil

# --- 対象のHTMLデータ ---
HTML_TEMPLATE = """<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Navigation Menu</title>
    <style>
        /* 全体のリセットと基本設定 */
        body {
            margin: 0;
            font-family: sans-serif;
            background-color: #f4f4f9;
        }

        /* メニューのスタイル（CSS） */
        .menu {
            display: flex; /* 横並び */
            list-style: none;
            margin: 0;
            padding: 0;
            background-color: #333; /* 背景色：ダークグレー */
            overflow-x: auto; /* 画面が狭い場合の横スクロール対応 */
        }

        .menu li {
            flex: 1; /* 各項目を均等な幅にする */
            min-width: 90px;
        }

        .menu a {
            display: block;
            text-align: center;
            padding: 16px 10px;
            color: white;
            text-decoration: none;
            transition: background-color 0.3s;
            white-space: nowrap; /* テキストの改行を防ぐ */
        }

        /* マウスオーバー時（ホバー）の動き */
        .menu a:hover {
            background-color: #555;
        }

        /* アクティブなメニューの色 */
        .menu a.active {
            background-color: #4CAF50; /* グリーン */
        }
    </style>
</head>
<body>

    <ul class="menu" id="nav-menu">
        <li><a href="index.html" class="active">トップページ</a></li>
        <li><a href="#">AndroidApp</a></li>
        <li><a href="#">Clang</a></li>
        <li><a href="#">Java</a></li>
        <li><a href="python3.html">python</a></li>
        <li><a href="#">windows</a></li>
        <li><a href="Linux.html">Linux</a></li>
        <li><a href="#">Chrome Book cm3</a></li>
    </ul>

    <script>
        // JS処理（必要に応じてページ移動などの処理を追加可能）
    </script>
</body>
</html>"""


def main():
    # 1. index.html を新規作成（既存のファイルがある場合は上書き）
    index_file = "index.html"
    with open(index_file, "w", encoding="utf-8") as f:
        f.write(HTML_TEMPLATE)
    print(f"[1/4 作成] {index_file} を作成しました。")

    # 2. index.html を python3.html にコピー
    python_file = "python3.html"
    shutil.copy(index_file, python_file)
    print(f"[2/4 コピー] {index_file} から {python_file} を作成しました。")

    # 3. ディレクトリ内のすべての .html ファイルを検索
    html_files = glob.glob("*.html")
    print(f"[3/4 検出] 更新対象のファイル: {html_files}")

    # 4. 各HTMLファイルのアクティブリンク（class="active"）をファイル名に合わせて更新
    for file_path in html_files:
        filename = os.path.basename(file_path)

        # ファイルの読み込み
        with open(file_path, "r", encoding="utf-8") as f:
            content = f.read()

        # 一旦、すべてのリンクから class="active" を削除
        # (CSS内の「.menu a.active」に影響が出ないよう、半角スペース+class="active"を対象にします)
        cleaned_content = re.sub(
            r'(\s+class="active")|(\s+class=\'active\')', "", content
        )

        # 自身のファイル名（例: python3.html）に合致するaタグにのみ class="active" を付与
        # 例: href="python3.html" -> href="python3.html" class="active"
        target_pattern = rf'href="{re.escape(filename)}"'
        replacement = f'href="{filename}" class="active"'

        updated_content = re.sub(target_pattern, replacement, cleaned_content)

        # ファイルに書き戻し
        with open(file_path, "w", encoding="utf-8") as f:
            f.write(updated_content)

        print(
            f"[4/4 更新完了] {filename} のアクティブ状態を「{filename}」に設定しました。"
        )


if __name__ == "__main__":
    main()
```

---

### 使い方・実行方法

1. 上記のコードを `setup_html.py` というファイル名で保存します。
2. ターミナル（Mac/Linux）またはコマンドプロンプト（Windows）を開き、以下のコマンドを実行します。

```bash
python3 setup_html.py
```

### 実行した結果
実行すると、同じフォルダ内に以下の2つのファイルが整った状態で出力されます。

* **`index.html`** のメニュー部分：
  `index.html` の「トップページ」に `class="active"` が適用されます。
* **`python3.html`** のメニュー部分：
  `python3.html` の「python」に `class="active"` が自動的に書き換わって適用されます。

（※もし今後、メニューにある `Linux.html` などをフォルダ内に追加して再度このスクリプトを実行すれば、自動的に `Linux.html` も認識して「Linux」のメニューがアクティブ化されます）
